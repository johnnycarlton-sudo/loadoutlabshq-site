Privacy

How this website handles your data, and where to find the Loadline privacy policy.

Loadline

The Loadline privacy policy explains what personal data the Loadline app handles, where it is kept and for how long. The data processing addendum covers how we process personal data for customers. In short, Loadline runs on Atlassian's cloud, keeps its data in Atlassian-hosted storage, and sends nothing to Loadout Labs or anyone else.

This website

  • This website uses no cookies, analytics or tracking, and it loads nothing from other sites: its fonts are served from this site.
  • It is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security purposes, as described in the GitHub General Privacy Statement.
  • If you email us, we use your email address and message only to reply and to provide support.
